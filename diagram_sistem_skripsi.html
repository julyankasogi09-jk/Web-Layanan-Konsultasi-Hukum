        bigint id PK

    USERS {
        bigint id PK
        bigint role_id FK "References USER_ROLES(id)"
        varchar nama_lengkap
        varchar username "Unique"
        varchar email "Unique, Nullable"
        varchar password "Bcrypt Hashed"
        varchar no_hp

        text deskripsi
        timestamp created_at
        timestamp updated_at
    }

    FORMULIR_KONSULTASI {
        bigint id PK
        varchar no_permohonan "Unique (REG/YYYY/MON/XXXX)"
        bigint klien_id FK "References USERS(id)"
        bigint pengacara_id FK "References USERS(id) - Nullable"
        bigint kategori_id FK "References KATEGORI_KASUS(id)"
        varchar tempat_lahir
        date tgl_lahir
        enum jenis_kelamin "L, P"
        varchar agama

        varchar status_sidang "Pemberkasan, Mediasi, Putusan"
        timestamp created_at
        timestamp updated_at

    PEMBAYARAN {
        bigint id PK
        bigint formulir_id FK "References FORMULIR_KONSULTASI(id)"

        varchar bukti_bayar "Path file bukti transfer"
        text keterangan
        enum status "belum_bayar, menunggu_verifikasi, lunas"
        timestamp created_at
        timestamp updated_at
    }

    PESAN_CHAT {
        bigint id PK
        bigint formulir_id FK "References FORMULIR_KONSULTASI(id)"
        bigint pengirim_id FK "References USERS(id)"
        text pesan
        boolean is_read "Status dibaca"
        timestamp created_at
        timestamp updated_at
    }
Penjelasan untuk Sidang Skripsi (Normalisasi 3NF): Pada skema awal, terdapat dependensi transitif di mana biodata klien diulang di formulir, dan tabel pembayaran memuat id_user secara redundan. Pada ERD 3NF yang diperbarui ini, setiap entitas non-kunci hanya bergantung langsung pada Primary Key miliknya. Pembayaran terikat secara unik ke formulir_id, dan seluruh data profil terpusat di tabel users.

Keterangan Aktor & Hubungan Relasi:
  • Klien: Mengakses katalog publik, mengajukan konsultasi baru (yang secara «include» menyertakan unggah bukti awal), mengunggah bukti bayar, dan chat konsultasi.
  • Sekretaris (Admin): Pusat operasional administrasi yang memvalidasi berkas, menjadwalkan temu resmi, menunjuk advokat, menerbitkan tagihan, memverifikasi lunas, dan mencetak laporan resmi.
  • Pengacara (Advokat): Menangani perkara yang ditugaskan, memberikan advis hukum di chat, mengunggah kontrak kuasa hukum, dan memperbarui status persidangan.

3.5 Activity Diagram: Konsultasi Daring (AJAX Polling Chat)

Pertukaran pesan dua arah tanpa reload halaman 
sequenceDiagram
    autonumber
    actor Pengirim as User Pengirim (Klien/Advokat)
    participant Browser as Browser UI (DOM)
    participant Server as Laravel Controller (ChatController)
    participant DB as Database (pesan_chat)
    actor Penerima as User Penerima (Advokat/Klien)

    Pengirim->>Browser: Ketik pesan konsultasi & klik 'Kirim'
    Browser->>Server: HTTP POST /chat/{id}/kirim (Fetch API + CSRF)
    Server->>DB: INSERT INTO pesan_chat (formulir_id, pengirim_id, pesan)
    DB-->>Server: Return ID Pesan Baru & Timestamp
    Server-->>Browser: JSON Response (Pesan Berhasil Terkirim)
    Browser->>Browser: Render gelembung pesan saya & Auto-scroll ke bawah

    loop Polling Setiap 3 Detik
        Penerima->>Browser: Halaman chat aktif di layar
        Browser->>Server: HTTP GET /chat/{id}/fetch?last_id=X
        Server->>DB: SELECT * FROM pesan_chat WHERE id > last_id
        DB-->>Server: Daftar Pesan Baru
        Server-->>Browser: JSON Array Pesan Baru
        Browser->>Browser: Append pesan baru ke chat box & Bunyikan notifikasi/scroll
    end

Keunggulan Arsitektur Sequence: Diagram urutan ini memvisualisasikan bagaimana prinsip MVC (Model-View-Controller) Laravel bekerja. Controller bertindak sebagai orkestrator yang menerima HTTP Request, memvalidasi input, mendelegasikan transaksi data ke Model Eloquent yang terhubung ke database MySQL, dan mengembalikan respon berupa tampilan Blade View yang interaktif.

    [*] --> DraftPengajuan : Klien Mengisi Form

    PendingVerifikasi --> Ditolak : Berkas Tidak Memenuhi Syarat
